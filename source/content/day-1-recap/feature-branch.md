# Feature Branch Approach

1. Define a **self-contained feature or modification**, with a clear scope and completion criteria.
2. Start a **dedicated branch** to implement only that feature.
3. Once implemented, ensure the changes are **compatible with the current state of the reference branch**.
4. **Merge into the healthy reference and retire the feature branch**.

**Remote-service tools** can formalize this approach:

- **Issues:** Define and discuss the feature's scope and completion criteria.
- **Merge/Pull Requests:** Document development on the feature branch, support review, and manage integration into the reference branch.
